# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the `main` branch. Please update to the most recent version before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Report them privately using [GitHub private vulnerability reporting](https://github.com/timlaing/music-assistant-alexa-api/security/advisories/new).

You will receive an acknowledgement within a few days. Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, including environment details (Home Assistant, Music Assistant and add-on versions)
- Any proof-of-concept code, if available
- Your preferred contact details for follow-up

Once a fix is confirmed and released, the advisory will be published and you will be credited unless you prefer to remain anonymous.
